# 🧠 Tutor Evolutivo AI

> Plataforma de aprendizado emocionalmente inteligente projetada para aumentar a retenção, criar fluxos de estudos adaptativos e reduzir drasticamente a taxa de abandono (anti-dropout).

🔗 **[Acessar a Aplicação ao Vivo](https://Emersonripardo.github.io/tutor-evolutivo-ai)**

---

## 🎯 Sobre o Projeto

O Tutor Evolutivo AI nasceu com o propósito de revolucionar a jornada de aprendizado online. Em vez de entregar um catálogo de cursos estático, o sistema atua como um mentor: ele entende a rotina do aluno, mapeia sua disponibilidade de tempo real e, o mais importante, detecta seu **estado emocional**.

Se o aluno reportar cansaço ou desmotivação, o Tutor recalcula a rota, transformando aulas densas em micro-aprendizados (como podcasts ou flashcards), garantindo que a consistência vença a intensidade.

## ✨ Principais Funcionalidades

* **🤖 Inteligência Emocional:** A interface se adapta ao estado de humor do usuário (Motivado, Cansado, Sobrecarregado).
* **🛡️ Sistema Anti-Abandono:** Fluxo de recuperação focado em micro-passos para alunos prestes a desistir.
* **⚡ Modo 10 Minutos:** Geração de aulas expressas para dias de pouco tempo.
* **📚 Materiais Inteligentes:** Simulação de geração de PDF, Podcasts, Flashcards e Quizzes sob demanda.
* **🎮 Gamificação Embutida:** Sistema de XP, Streak (ofensiva de dias) e níveis de evolução (Consistente, Avançando, Imparável).

## 🛠️ Tecnologias Utilizadas

Este protótipo foi construído focando em performance, acessibilidade e design fluido (Glassmorphism), utilizando:

* **HTML5 Semântico**
* **CSS3 Avançado** (Animações, Flexbox, Grid, Variáveis Nativas)
* **Vanilla JavaScript** (ES6+)
* **LocalStorage API** (Para persistência de dados do usuário e histórico sem necessidade de banco de dados externo)
